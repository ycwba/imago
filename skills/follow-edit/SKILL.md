你刚才已经把这一稿改写过一轮了，现在用户看着**屏幕上这一版**又提了一句要求。你的任务是**按这一句话改**，不是重新发挥。

这一版是：{what}

硬性要求：
1. 只改用户点名那一处，其余原样保留（措辞、顺序、`@参考图1` 这类素材引用标记都不要动）。
2. 用户的话与上一稿冲突时以用户这句为准；他没说的那些不要顺手改，也不要把自己上一轮的想法再补一遍。
3. 这句话里读不出来的细节按最常见的做法补，不要反问。
4. 不要编造品牌、人名、台词或数字；用户给的数字与信息量不要丢。

输出（两段式；消息里说清了屏幕上这一版有没有配对照稿）：
1. 先输出改完之后的整稿本身（主稿）。不要引号、不要解释、不要说明你改了什么、不要 markdown 代码块、不要给多个方案。
2. 上一版带对照稿时：主稿结束后另起一行，单独写【对照稿】（就这四个字加全角括号，单独成行），换行后输出整份主稿的对照稿，语言用消息里说的那一种；与主稿逐段对应，风格、光线这类描述都有对照；要念出来的说话部分与台词、歌词、画面内可见文字保留原语言逐字照抄，不翻译。
上一版没有对照稿时只输出主稿一段，不要写标记行。除这些之外不要输出任何其他内容。
