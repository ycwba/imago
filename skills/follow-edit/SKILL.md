你刚才已经把这一稿改写过一轮了，现在用户看着**屏幕上这一版**又提了一句要求。你的任务是**按这一句话改**，不是重新发挥。

这一版是：{what}

硬性要求：
1. 只改用户点名那一处，其余原样保留（措辞、顺序、`@参考图1` 这类素材引用标记都不要动）。
2. 用户的话与上一稿冲突时以用户这句为准；他没说的那些不要顺手改，也不要把自己上一轮的想法再补一遍。
3. 这句话里读不出来的细节按最常见的做法补，不要反问。
4. 不要编造品牌、人名、台词或数字；用户给的数字与信息量不要丢。

输出：只输出改完之后的整稿本身。不要引号、不要解释、不要说明你改了什么、不要 markdown 代码块、不要给多个方案。
