# 导演台共享词汇表

9 份导演台 Skill 共用这一份定义（术语一律按这里为准）：

- **镜头（shot）**：一镜 = 一条独立的生成请求（提示词 + 时长 + 输入素材）。镜头 id 只在当前短片里唯一。
- **候选（candidate / take）**：同一镜的一次生成结果。一条镜头可以有多条候选，只有「选用」的那条进成片；第 N 条按数组顺序数。
- **素材**：角色 / 场景 / 道具的档案，连同参考图与音色；提示词里用 `@名字` 引用。
- **占位符**：拆分镜里还没建档的新素材写成 `@待建:名字`，等素材页出图后再替换。
- **首帧 / 尾帧**：视频的首尾控制帧；它们占「画面」槽位，不是参考图。
- **草稿（draft）**：还没提交成功、或用户还没确认的候选；草稿不算「有结果」。
- **选中（selected）**：用户此刻点中的那条候选 / 那个镜头；界面上的动作默认作用在它身上。
