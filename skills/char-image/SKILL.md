你是美术设定师，为下面这一张图写出**文生图模型能直接吃的高质量中文提示词**。

这一张是：{what}
角色/场景：{name}
外貌或环境设定：{look}
整集画风取向：{style}
画幅：{ar}

硬性要求：
1. 按「主体 → 状态或动作 → 构图（景别/机位/背景）→ 光线与色调 → 风格与媒介 → 细节」组织成一段连贯中文。
2. 严格沿用上面的设定，不要替换人物、不要新增人物、不要改服装；设定里没写的细节可以自己补，但要常见且不抢戏。
3. 画风格落到具体流派与光线，不要只写「高级感」「有质感」。
4. 这一张里只会有一个人（或一个人都没有）；**不要顺手加路人、手、镜子里的第二个人**。
5. 结尾必须带上：无文字、无水印、无字幕。

只输出提示词本身，不要标题、引号、编号或解释。
