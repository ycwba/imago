平台密钥保存在浏览器本地，随请求经本地代理发往对应平台；留空则使用本地代理的 .env / 环境变量里的密钥（代理程序本身不带任何密钥）。

供应商与密钥

按生成类型分开配（图片 / 视频 / 语音 / 文字 AI），只列本机在用的：添加进来的，或密钥已经有着落的（这里填了 / .env 里有）。找不到某家就是还没接进来，用右边的按钮加。 「识图能力」是全局一项，只画在当前「作用文字 AI」的那张卡下面。

添加自定义供应商（中转站 / 网关 / 企业部署）

两种接法：①「供应商」选一家内置平台，接口地址自动填好它官网的地址，贴上密钥点添加； ② 选末尾的「自定义」再挑一个接口形状（OpenAI 兼容 / H3 兼容…），地址与密钥填你自己的。 建出来的都是独立的一家：不设家数上限。 接口形状真不一样的平台要改 proxy.js 的 REGISTRY，这里不猜字段。

网络与刷新

列表分页

「动态加载」= 滚到列表底部自动续拉，不再有「加载更多」按钮。

外观与界面

界面长什么样、列表默认怎么摆，跟着数据文件走（换台机器还在）。 改完就自动存进本机；主题与左栏当场跟着变。

产物存放

生成完的产物留在哪、优先从哪读、列表里要不要只显示本机有的。三项连着看：关掉「自动存本机」后， 新产物只剩平台外链，而外链过一阵会过期 —— 那时卡片就变成裂图了。第三项要前两项都开着才生效， 前两项没开着时这一行整个收起来（画着却不生效等于骗人去勾）。

素材库

这几项只作用于「素材库」那一页：界面上的说法与真的发给文字 AI 的参数是同一个开关。

AI 助手

右下角那个悬浮球 / 右侧抽屉（Ctrl + / 开合）。它读本机数据不用问； 动手（提交一次生成、改一项设置）默认要你在卡片上点「执行」。
关掉只是不装这一层：对话记录、附件身份、你提交过的那几条任务都原样留着， 重新勾上就全部回来。改完刷新一下页面才生效 —— 助手是页面加载时装上的。
勾上之后助手校验完就立刻执行，不等你点确认。一次生成在平台那边就是一条真任务， 没把握就别勾。
「吸住」与「任务提醒」还有这个总开关都是本机窗口的事，不跟着云同步、不参与整包备份。
系统通知的授权怎么做
球上的数字不需要授权；系统通知要浏览器点头，所以有上面那颗「现在授权」。 拒过一次浏览器就不再问，得去地址栏左边的「网站设置」里手动放开。 它只提醒助手替你提交的那几条 —— 你在页面上自己点的任务由那一页的列表接着刷。

润色指令

按用途分成几类，每一条的默认文本都写好了（见 assetlib.js 的 TextAI.DEF）。确实要改再展开。
润色前要不要先反问用于：三个「AI 润色 / 帮我完善」入口（要 JSON 的那几条不走反问）
「AI 判断」= 先让文字 AI 读一遍你的描述，它自己决定是先反问几个问题、还是直接润色 （按「补上这些会不会明显改变成片效果」判断，不按字数）。你答完的答案会当硬约束写进润色。

清理缓存

这四项都是能自己重新生成的缓存，清掉不会少任何作品（图片 / 视频 / 语音、提示词归档、收藏、历史一律不动）。 换密钥、平台改了参数又不想干等过期时用这一栏最快。
平台接口应答 平台返回的列表 / 任务详情 / 产物地址 / 能力表 / 报价的副本。换了密钥或平台改了参数时清它，下次打开重新拉。
文字 AI 型号能力 每个文字型号「能不能识图」的判定（缓存 12 小时）。换了文字型号、或某个型号突然支持识图了就清它，下次润色时重新判。
缩略图与体积探测 视频首帧与图片小图的本地副本，加上上传前的体积测量（存 IndexedDB）。清了下次看列表会重新抽帧，视频多时 CPU 忙一会儿。
「没归档到」标记 哪些任务的提示词在本机归档里找不到（免得反复去问同一个任务号，只在本标签页有效）。手工补过归档文件或换过归档目录后清它。

设置备份与恢复

上面每一栏改完就自动存进本机，这里三项管的都是整份设置：导出成一个 JSON（可换电脑导入）、从 JSON 恢复、清回出厂状态。 导出默认不含密钥，选了含密钥那份文件里就是明文，别外传。
