## 1. 主张

> **界面退到片边，画面站到中间。**

拾帧是个**创作工具**，工具的职责是让作品被看见，而不是让工具被看见。所以这一稿做三件事：

1. **界面近乎无彩** —— 冷银灰底、墨色字、一道发丝描边。颜色全留给生成的画面与状态。
2. **只留一枚信号色** —— 蓝晒 `#0E6F8C`。选中 / 进行中 / 链接 / 焦点，全是它。
3. **三把嗓子 + 一个记忆点** —— 字分「片名 / 正文 / 数据」，记忆点是**齿孔**。

---

## 2. 为什么不是现在这样

现状是**一整套通用的 SaaS 语言**：淡紫灰底 `#F2F3F9`、白卡、两枚紫（`--acc` 靛 + `--pri` 紫罗兰）、
10–14px 圆角、每张卡一层软影、全站一种黑体。它干净，但也**不像是给拍片的人用的** ——
换任何一个 AI 看板都长这样。

这一稿把它换成**一间剪辑室**的样子：机器是冷的，画面是热的。

## 4. 字

| 角色 | 字体 | 用在哪 |
| --- | --- | --- |
| 片名 DISPLAY | `Bahnschrift`（拉丁）+ `宋体`（中文） | 页面名、栏目标题、大标题。**不大段用** |
| 正文 BODY | 系统黑体（苹方 / 雅黑） | 说明、提示、卡片正文 |
| 数据 MONO | `Cascadia Mono / Consolas` + 表格数字 | 计数、编号、时间码、金额、尺寸、字节数 |

字号档：`34 / 22 / 16 / 14 / 13 / 12`（数据列 12，等宽）。
字距：片名 `+0.06em`，小字 `+0.02em`，正文 `0`。
行高：正文 1.7，标题 1.25–1.45。

**为什么数据那一列必须等宽**：它要能上下对齐着看 —— 计数、金额、时间码成列时歪一点就读不成列。

---

## 5. 签名：齿孔

只留一个记忆点。齿孔是胶片的边缘，也是「**还在走**」的意思：

- **走片进度**：进度条是一根实色条，齿孔打在上面、往下走 —— 一眼看出「还在跑」。
- **页面身份**：左缘一条 12px 的齿孔边 + 一串竖排片边码（`KS 4471 · 拾帧 · A-01`）。
- **印相装订**：接触印样上缘的齿孔边。
- **空态**：空的那一格用齿孔表示「这一卷还没开始」。

另外三件配套的小工具：

| 件 | 是什么 | 解决什么 |
| --- | --- | --- |
| 片边码 EDGE CODE | 每条产物一串 `KS 4471 / 03`（卷号 / 张号） | 同一件东西在目录、账、导出文件名里都是同串字 |
| 帧位刻度 FRAME TICKS | 一格一格数（`01 02 03 04 05`） | 比「第 3 个」更接近剪辑：切在哪一格看得见 |
| 状态在左 STATUS FIRST | 一行里按「状态 · 归属 · 时间」排 | 一屏几十张卡，先看到的是它好不好，不是它叫什么 |

## 6. 控件与件

- **按钮**：小圆角（4px）、发丝描边；主按钮是实心蓝晒，次按钮白底描边，磁贴 32px 方。
- **选中态**：一道 2px 蓝晒色条 —— 不靠阴影，不靠换底色跳色。
- **状态标**：淡底 + 深字（小圆角 2px），不靠图标。
- **卡片**：默认**无影**，靠发丝线分面；浮起来的东西（灯箱、弹窗）才有一层影。
- **数据**：所有数字一律等宽 + 表格数字。
- **页头**：身份铭牌（26px 方块 + 强调色）+ 标题（片名字体）+ 上下文 + 动作 —— 与产品现状那一条契约一致，只是换了形状。

## 8. 和现状的对照

| | 现状 | 这一稿 | 为什么 |
| --- | --- | --- | --- |
| 底色 | `#F2F3F9` | `#E8ECEF` | 淡紫灰像后台系统；冷银让画面跳出来 |
| 强调色 | `#6957E8` / `#7C5CFF` | `#0E6F8C` | 两枚紫分不清「选中」和「强调」，收到一枚 |
| 圆角 | 10–14px | 4–8px | 仪器感，不是气泡感 |
| 描边 | 淡紫 1px | 冷银 `#D2DBE1` | 发丝线分面，影子留给浮层 |
| 字 | 全站黑体 | 宋 + 黑 + 等宽 | 界面与素材在字上就分得开 |
| 数据 | 混在正文里 | 等宽 + 表格数字 | 成列的计数、金额、时间才不歪 |

## 9. 落到产品时改哪几处

1. `web/styles/tokens.css`：① 段主题色换成这一稿的两组值（浅 + 深各一套），其余各段不动。
2. 圆角档位收敛成 `2 / 4 / 8 / 999`，间距收敛成 `2 / 4 / 6 / 8 / 12 / 16 / 20 / 24 / 32`。
3. 页面里的软阴影删掉（`ui.css` 那一批 `--shadow-*` 只留浮层用），改由发丝线分面。
4. 字体加一枚片名（宋体族），数据列统一走等宽。
5. 页头、卡片、状态标、翻页行按这一稿的形状重画一遍 —— **只改样式层，不动结构**。

**判据影响**：G19（主题色成对）按 §3 的两组值写；G18（裸值）新增取值都进令牌；
G21（透明度阶梯）里的淡底一律走 `color-mix(…)`；G20（页面不顶层定义公共类）不受影响。

## 10. 要拍板的

1. **蓝晒这一枚够不够？** 现在信号色只有它一枚。若将来要区分「生成中」和「选中」，得再开一枚（那时建议加**暖橙**，别再开蓝）。
2. **片名用宋体，接受吗？** 中文宋体（`SimSun` / `Songti SC`）在 Windows 与 macOS 上不是同一副脸；不想要宋体就把片名改成窄体无衬线（`Bahnschrift` + `思源黑体`），风格会往「设备面板」靠一点，少一点「片头字幕」。
3. **齿孔要不要真的动？** 走片进度条的孔在动。`prefers-reduced-motion` 下已停；要不要连这个也停（改成静态孔），看你的偏好。
4. **齿孔边占 56px 的左缘**，比现状侧栏窄态（56px）一样宽 —— 与侧栏并存时会不会撞，要落到真机上看。

## 11. 这一稿没做的

- 不复刻任何一页真实界面（这稿只定风格）；七个页面套上之后的实际密度要落到真机上再看。
- 不涉及图标集与插画；铭牌那个字形是临时占位。
- 不涉及动效曲线（只做了一次进场编排 + 走片）；页面转场那套留到下一轮。
