# 素材库 —— 重设计稿（浅色主题）

> **这一稿已经落进产品**（2026-10-25）。真机效果见 `design/materials-detail/shots/`：
> `01-素材台.png` `02-检查器.png`（那一稿的 `03-详情层.png` 是点「打开详情」之后的整屏层）。
>
> 这一稿要回答的问题只有一个：**素材库的布局该怎么重排**。
>
> 这一稿是**浅色稿**，但**夜间版不用另外设计**：产品令牌里的深色档一换主题就成立，
> 这一稿的深色档就是**同一个稿子把 `data-theme` 换成 `dark`** 自动派生出来的
> （深色覆盖见 `web/styles/tokens.css`）。
>
> 稿子里的 10 条素材（人物、场景、道具）与 9 张缩略图是**编的** —— 一个校园题材的小剧组，
> 只为把布局看清楚，不代表库里真有这些内容。

## 1. 改造前的三个问题（都指到真品）

### ① 屏幕第一屏全是控件，一条素材都看不到

真品的素材库从上到下是：标题 → 一段介绍 → `.toolbar`（筛选芯片 / 搜索 / AI 找素材 / 计数）
→ `.toolbar2`（分组 / 一次出齐 / 存回本机 / 停下 / 多选 / 视图 / 新建）→ `.toolbar3`
（出图型号 / 出图张数 / 语音型号）→ AI 活区 → **素材体检面板** → 才轮到卡片网格。

四行工具条加一块体检面板，四百多像素高（`spa-chars.css` 里 `.toolbar2/.toolbar3` 的
margin 就是这个布局的指纹）。1440×900 的窗口里，用户第一屏看到的是控件，不是自己的演员。

### ② 「体检」是报告，「缺口筛选」是动作 —— 两处在说同一件事

`.char-health` 那四行（缺预览图 / 缺角色资产 / 缺声音 / 缺描述）说的是一批数据；
筛选芯片里的四个缺口档（`nopic` / `noasset` / `novoice` / `nodesc`，见 `chars.js` 的 `FILTERS`）
点下去筛的也是它们。用户要自己把「缺 12」翻译成「该点哪一档」，
而体检面板本身不能点（点了才跳到对应筛选，是一次二次跳转）。

### ③ 编辑在卡内就地展开，把网格撑坏

`chars.js` 的 `editHTML(c)` 展开在卡片内部（`.card.open .edit`），一个角色要编辑
画面 / 候选 / 角色资产 / 身份锚点 / 使用关系 / 声音 —— 一张卡能长到一千多像素。
`spa-chars.css` 里那几条 `.grid.view-list .card.open .thumb` 的补丁就是这件事的症状
（得专门把图钉回 150px，不然预览图被拉成一条几倍高的色块）。

卡面本身也很薄：图 + 名字 + 徽标 + 一排小按钮。描述、角色资产、声音、
「被几镜引用」这些最有用的信息，全都藏在展开区里 —— 不点开就不知道。

三段（外加应用侧栏）：**目录轨 · 素材台 · 检查器**。

- **目录轨**（208px）：类型 / 还缺什么 / 分组 / 本页出图设置。**它取代了原来的
  筛选芯片行 + 三行工具条 + 体检面板**，四样东西合成一条目录。
- **素材台**：一行工具（搜索、AI 找素材、视图、多选、新建）+ 卡片网格 + 底部翻页行。
- **检查器**（340px，点一张卡才占位）：编辑、声音、锚点、使用关系都在这里。
  **取代了「卡内就地展开」**。

## 4. 签名件：完备度点阵

每条素材有四个槽位 —— **预览图 · 角色资产 · 声音 · 描述**，卡面右下角四枚小方块：

| 形状 | 意思 |
| --- | --- |
| 实心（`--ok`） | 有 |
| 描边 + 45° 斜纹（`--warn`） | 缺 |
| 一条短横（`--line`） | 这一类不需要（场景不要声音，道具不要角色资产） |

**同一套形状语言在三个地方复用**：卡面（这一位齐不齐）、目录轨「还缺什么」（哪一类缺几个）、
检查器顶部（这一位的四项明细 + 一行图例）。所以「卡上那四块」不用解释也能看懂，
因为左轨已经用同一个形状讲过一遍。

刻意没用颜色去区分类型：AGENTS §3.4.2 说共享界面的状态色只取 ① 段，
角色的类型靠**文字徽标**（「角色 / 场景 / 道具」）说，不用固定色。

## 5. 令牌与公共件：这一稿没有另起一套

稿子里的颜色、圆角、间距、字号**全部来自产品真文件**：

| 借谁的 | 借了什么 |
| --- | --- |
| `web/styles/tokens.css` | 主题色、间距、字号、圆角、阴影、动效、深浅两档 |
| `web/styles/ui.css` | `.tool` `.ghost` `.pri` `.chip` `.viewtoggle` `.pager-row` `.pginfo` `.bulkbar` `.bk-cnt` `.bk-tip` `.ui-inp` `.ui-ta` `.ui-tag` `.ui-cand` `.ui-hint` `.empty` `.card-surface` |
| `web/styles/sidebar.css` | 整个应用侧栏（图标 + 两字短标签的窄形态、余额块、换背景） |

稿子自己的样式只有「这一页的排版」：`demo-materials.css`，全部挂在 `.mat-*` / `.mcard` 这类
页面自己的类名下，没有另定义任何公共类。

**三个 demo 作用域的临时值**（落地时回 `tokens.css`）：

```css
--rail-w: 208px;   /* 目录轨宽 */
--insp-w: 340px;   /* 检查器宽 */
--font-mono: ui-monospace, "Cascadia Mono", Consolas, monospace;
```

等宽字体是给**计数**用的（目录轨右边的条数、卡面的「被 6 镜引用」、检查器的条数）——
数字要能上下对齐着看，这一列才像一列。系统字体里就有等宽，不用外链字体
（产品 CSP 是 `font-src 'self' data:`）。

## 6. 落到产品里要做的事

1. **目录轨的组名与计数从 DOM 现读** —— 照设置页目录轨的规矩（AGENTS §3.4.3），
   JS 里不许有第二份清单；轨上每行的当前值现读同一份真相。
2. **翻页行仍在页面底部** —— AGENTS §3.4.3 的口径：普通页的翻页行在页面底部。
3. **卡面那一排动作收进公共件** —— 稿子里是 `.macts` / `.mg`（悬停浮出），
   真品里不要在页面里另抄一份（现在 `chars.js` 的 `Wb.actsHTML` 已经有一份，
   应当扩它，不是再写一个）。
4. **多选勾选框复用公共 `.pick` 那一套**（`.task .pick` 现在只覆盖横排任务卡，
   竖排卡要扩到 `.mcard`）。
5. **三类的槽位不一样** —— 场景不需要声音与角色资产，道具只需要预览图与描述；
   点阵里的「不适用」就是这一条的落点，不要给道具画「缺声音」。
6. **本页出图设置改名「本页默认」** —— 详情页里每个生成位（预览图、角色资产、声音）都自带
   型号与数量的选择，这里只提供新开出来的默认值；「用本页默认」那颗链接负责把它收回来。
   **2026-10-25 修正**：这一整块撤掉了 —— 页面上不留任何「默认面板」，
   默认值改由设置页「素材库」那张卡管（默认生图型号 / 默认语音型号 / 默认一次出几张）；
   详情层那颗「用本页默认」链接也一并删掉。
   **2026-10-25 再修正**：左轨那行「出齐用哪个型号」也撤掉了 ——
   「出齐」用哪个型号只有一处出处（设置页那个默认生图型号），左轨不再挑。
   详见 `design/materials-detail/DESIGN.md` §4.1。
7. **窄窗（≤1180px）两列都改覆盖式** —— 目录轨变覆盖抽屉（头栏出「目录」），
   检查器从右侧盖上来；内容区一列都不占。
8. **判据** —— 视觉回归（`tests/e2e/ui-visual.cjs`）要加这一页的档位：
   网格 / 检查器 / 多选 / 窄窗，各浅深两档。

## 7. 顺手发现的一个真品问题（不在本稿范围，只是记一笔）

**深色档下，原生控件（`select` / `input` / 滚动条）的文字是黑的。**
UA 样式用 `fieldtext`，不看 `--txt`；页面没声明 `color-scheme`，所以
深色档里的 `select` 是「深底 + 黑字」。这一稿里是这么绕过去的：

```css
html[data-theme="dark"] { color-scheme: dark; }
```

建议在 `tokens.css` 的深色档补这一句（一行，全站受益）。
本稿**没有改** `tokens.css`。

## 9. 这一稿没有回答的问题

- **筛选的组合**：稿子里一次只能筛一档（类型 / 缺口 / 分组 三选一）。
  真实的「角色里缺声音的那几条」是两级组合，要不要支持、怎么表达，值得单独议。
- **列表档**：稿子里的列表档只是把网格压成竖排，没有单独设计；
  真品的列表档另有 `.grid.view-list` 一套壳，重排时别把它忘掉。
- **导演台的引用关系**：检查器里的「使用关系」只是几行字；
  能不能从导演台那边点过来、或者反着从这条素材跳回那一镜，这一稿没定。
