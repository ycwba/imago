## 1. 这一稿的一句话

> **一张卡就一张卡；详情在原界面里打开，不另起一层。**
> 状态只换卡里的内容，不换这张卡的样子；详情就把那张卡自己展开，
> 展开的东西还在它原来的位置上。

## 2. 相对上一版（v1）改了什么

v1 那一版我给的是「右检 + 诊断条带子」，这一版**两处都推翻**：

| v1 | v2 | 为什么 |
| --- | --- | --- |
| 失败卡做成**一条通栏的带子**（没有缩略图、文字摊满 1300px） | 失败卡回到**同一副骨骸**：左边一格 132×96 的槽 + 右边一列字 | 一张通栏的带子**根本不像一张卡**。页面上一半是卡、一半是带子，扫不下去 |
| 详情开在**右检**（宽屏是另一栏，窄窗是覆盖式浮层） | 详情**就地展开**：那张卡自己变高 | 右检是**另起一层**。这一页要的是「一边扫列表一边看某一条」，另起一栏就把列表挤窄、浮层就把列表盖住 |
| 诊断条三行（是什么 / 平台原话 / 代价与动作）独占一整行 | 同样的三行，**塞回卡片的骨骸里**：状态牌 + 一行平台原话 + 动作行 | 异常也是一张卡。它比成功卡多一行字（平台原话），但**宽度、结构、左边缘一模一样** |

保留下来的：页头三档计数、代价写在按钮上、平台原话用等宽、账条「人话无衬线 / 机器记账等宽」。

## 3. 改造前的两个问题（都指到真品）

对照图：`design/assets-layout/shots/before-现状-资产库.png`（1440×900，侧栏收成 56px）。

### ① 详情在卡里就地展开，把网格撑坏

真品：`web/pages/assets.js:576-580` 的「详情」按钮把 `Wb.detail` 渲染进卡里的 `.cdet`
（`web/styles/ui.css:212` 的 `.tdetail, .cdet`）：

```js
const open = detBox.style.display === 'block';
detBox.style.display = open ? 'none' : 'block';
if (!open) window.Wb.detail.render(a, detBox);
```

`Wb.detail` 那一份（`web/ui/workbench.js:1216`）渲染出来是**提示词全文 + 十几行参数账条**，
一条产物的详情一展开，卡会长到两三百像素 —— **一条卡把整行的几何撑坏**。

问题不在「就地展开」这件事本身（就地是对的），而在**展开的东西是卡内的一个盒子**：
盒子在卡里，卡就被撑成两三百像素，旁边的格子旁边留一块空白。

**就地展开与撑坏网格不是一回事**：展开的东西在卡**自己这一行**里长出来
（下面几行顺移、别的卡不动），网格就不会被撑坏 —— 这是这一稿要做的事。

### ② 失败不是一颗红点 —— 平台原话**根本没画在卡上**

真品的失败卡，缩略图那一格里只写一个红字「生成失败」
（`web/pages/assets.js:470` 的 `assetCardHTML`），而
**平台返回的原话（`failMsg`）压根没有画在卡上**：
`assets.js:267` 把它存进 `a.failMsg`，但 `assetCardHTML` 里没有一处用它；
它只在 `Wb.detail` 的「错误」那一行里露一次脸（`workbench.js:1358`）——
**想看「为什么失败」，必须先点开「详情」，而点开详情又会撞上上面那个撑坏网格的问题。**

「结果未知」那一档尤其不该被当成一个小状态：真品对它格外谨慎
（`workbench.js:1634` 的按钮已经写成「重发（可能再扣一次费）」），
**可那句警告只在点开之后才看得到，卡上那一格是个绿点 —— 绿点在产品里是「已完成」。**

### 4.1 一张卡就一张卡：五种状态共用一副骨骸

**骨骸**（产品的 `.task`，一个字没改）：左边一格 132×96 的槽（`--sz-tile` × `--sz-thumb-h`），
右边一列字：状态点 + 状态词 + 徽标 + 时刻 / 提示词 / 来源行 / 动作行。

**状态只换槽里的内容**：

| 状态 | 槽里是 | 字里多一行 |
| --- | --- | --- |
| 已完成（图片 / 视频） | 画面 | —— |
| 已完成（音频） | 音符块（accent 渐变，产品已有那一档） | —— |
| 生成中 | 琥珀牌：「生成中 / 已跑 2 分 14 秒 / 进度条」 | —— |
| 排队中 | 中性牌：「排队中 / 第 2 位」 | —— |
| 生成失败 | 红牌：「生成失败 / 429 限流」 | **平台原话**（等宽，一行，截断） |
| 结果未知 | 琥珀牌：「结果未知 / 可能已扣费」 | **平台原话**（等宽，一行，截断） |

于是**异常卡与成功卡的宽度、结构、左边缘完全一致**，只多出一行字（平台原话）。
一屏 14 张卡扫下来，坏掉的那几张靠**牌子的颜色**就能挑出来，
不用去看那一行等宽字。

**状态牌的规矩**：牌是「这块槽里没有画面，但有话要说」的样子 ——
底色用状态色的淡底（`--a-10` / `--a-12`），字两行：状态词 + 一个短因。
短因就是平台原话的第一口气：`429 限流` / `审核未过` / `503 服务不可用` / `平台没回执`。

### 4.2 详情：就地展开，不另起一层

- **不另起一层**：没有右检、没有抽屉、没有遮罩、没有浮层。
  展开的东西**就在那张卡原来的位置上**。
- **怎么打开**：点卡上的「详情」（或卡身）→ **那张卡自己变高**，
  字列从摘要换成详情；下面几行顺移，**别的卡不动、网格不变形**。
- **怎么收起**：再点一次「收起」，或按 Esc。一次只开一条。
- **展开区里有什么**：
  - 异常条目先给一块**诊断块**：平台原话**给全句**（不截断）+ 代价。
  - **这一条的账**：状态 / 型号 / 平台 / 类型 / 格式 / 比例 / 分辨率 / 画质 /
    时长 / 体积 / 费用 / 积分 / 创建 / 耗时 / 任务号 / 资产号。
  - **完整提示词**（与 `Wb.detail` 同一份 `.det-prompt` + 复制按钮）。
  - **参考图 / 输入图**（与 `Wb.detail` 同一份 `.det-refs`）。
  - **多出来的动作**：完成品才有（收藏 / 复用 / 删除本机这一份）。
    异常条目的动作（去平台看 / 重试 / 取消）**始终在卡面那一排**，
    不在展开区里再出现一遍。
- **就地展开的好处**：宽度是整行的 —— 参数表能排成**三到四列**
  （窄窗自动收成三列），不用像窄面板那样挤成一条长龙。

### 4.3 网格档（方块档）里怎么展开：那一行不动，带子接在它下面

网格里不能照搬清单档的做法：**格子长高，会在同一行别的格子底下留出空洞** ——
网格最怕这种（一行格子底边不在一条线上，整片墙就散了）。

所以这一档的做法是：

```text
┌──────────────────────────────────────────────────────────────┐
│ [格][格][格][格][格][格]     ← 那一行**一个像素都不动**      │
│              ┌ ↑ 连线：从带子的上沿指回那个格子 ────────┐    │
│              │ 结果未知 · SparkCine · task_9d40aa17  [收起]│    │
│              │ 平台原话 提交已发出，但平台没有回执：…      │    │
│              │ 已扣 2 积分 · 重发可能再扣 2 积分            │    │
│              │ 这一条的账（横着排五列）…                     │    │
│              └────────────────────────────────────────────┘    │
├──────────────────────────────────────────────────────────────┤
│ [格][格][格][格][格][格]     ← 下面的行整体下移一行           │
└──────────────────────────────────────────────────────────────┘
```

- **那一行保持原样**：格子的大小、位置、底边，一条都不变。
- **带子是整行宽的**，插在它那一行的下面（不是覆盖，是往下长）。
- **连线指回那个格子**：横坐标是**量出来的**（量那个格子与带子的矩形，写进 CSS 变量），
  换成第 2 列、第 3 列，线也跟着挪。线头上一个朝上的小三角指着格子。
- 带子里的内容与清单档的展开区**同一份**（账条 + 提示词 + 参考图 + 动作）。
- **一次只开一条**；再点一次或按 Esc 收起。

**这一档落地的代价是明摆着的**：**一行几格必须先分好组**，展开才能插在它那一行的下面。
真品现在是 `auto-fill` 自动分列 + 卡内追加 `.cdet` ——
**自动分列与「插在行下面」不能同时成立**，这一页得改成：
JS 按容器宽度算出��行几格 → 显式分组 → 展开插在行下面 → 量出连线位置。
（上一稿 `design/assets-layout/` §5 已经算过这笔账，结论一样。）

### 4.4 代价写在按钮上

- 「重试」是补救动作，不是危险动作 —— **不染红**。红色留给「这条坏了」本身（牌子、状态词）。
  只有**「结果未知」**那一档的重发按钮是琥珀的：它要提醒的是「重发可能重复扣费」
  （真品的 `workbench.js:1634` 已经用 `.rt.warn` 这么写，这里只是**把它提到卡面上**）。
- 卡面上那一行：**「已扣 6 积分 · 重试会再扣 6 积分」**紧挨着
  **「重试（会再扣 6 积分）」** —— 中间隔一整张卡的距离就等于没说。
- 审核没通过那一档写的是「这次**没有扣积分** · 改完提示词再重试不花钱」——
  **要改的是提示词，不是重试**，这句话只在「平台原话」里是看不到的。

### 4.5 页头三档计数 + 筛选收成一行

「在制 / 失败 / 结果未知」提到页头（真品是第五颗「状态」芯片）：
每一档带条数、点一下把列表筛到那一档；**计数为 0 的那一档不画**
（库里没有失败的时候，页头不该挂着一颗「失败 0」）。

筛选从四行收成两段：

```text
┌ 页头 ───────────────────────────────────────────────────────────┐
│ 资产库   ● 在制 3  ● 失败 3  ● 结果未知 1                       │
│ 搜索 [提示词/资产ID/任务ID…] [搜索] [AI 检索]   [清单|方块][多选][刷新] │
├ 一行筛选 ────────────────────────────────────────────────────────┤
│ [全部 14][图片 7][视频 6][音频 1]   平台▾   时间▾   当前 14 条  │
└──────────────────────────────────────────────────────────────────┘
```

- **类型**那一排芯片**带条数**（真品原来不带）。
- **平台从一个下拉走**：平台涨到十几家时，一行十几颗芯片会把整行撑开。
- **时间也是一个下拉**（全部 / 今天 / 近 7 天 / 近 30 天 / 自定义区间）；
  选「自定义区间」时后面才露出起止日期 —— 区间那一套判据仍然只有一份。
- **搜索框与 AI 检索挪到页头**：它们是「找东西」，不是「筛选条件」。

计数口径一条规矩：**页头三档 = 在当前其它筛选条件下的条数**，点一下就得到这个数，不会对不上；
类型芯片的计数同样跟着筛选走。

### 4.6 账条的排版规矩

**人话用无衬线，机器记的账用等宽** —— 型号、体积、费用、积分、创建时刻、任务号、资产号走
`--font-mono`；状态、平台、类型、画质、时长走正文体。
产品里这条规矩已经有一半（`.did` 用 monospace），这一稿把它说全了。

## 8. 顺手发现的真品问题（不在本稿范围，只是记一笔）

### ① 全项目没有一处声明 `color-scheme`

`web/styles/` 与 `shell.html` 里都搜不到 `color-scheme`。

建议在 `tokens.css` 的深色档补这一句（一行，全站受益）。**本稿没有改 `tokens.css`。**

## 10. 这一稿没有回答的问题

- **一次只开一条**：展开第二条时第一条自动收起。
  「同时开两条对照着看」也许有人要 —— 那是另一套交互（并排两列），这一稿没做。
- **展开时的高度**：账条 + 提示词 + 参考图加起来约 400–500px。
  宽屏一屏放得下，窄窗要滚。**要不要给展开区一个自己的滚动**（高度封顶），
  这一稿没定 —— 现在是它长多高就多高。
- **方块档的格子本身不展开**：格子是预览（画面 + 状态 + 提示词 + 平台原话两行），
  展开的是**行下面那条带子**。代价是：**格子那一行与带子之间隔着一条缝**，
  要靠一根连线才知道带子说的是哪个格子 —— 这根线是量出来的，换列会跟着挪。
- **带子的高度**：账条 + 提示词 + 参考图加起来约 400–500px。宽屏一屏放得下，
  窄窗要滚。**要不要给带子一个高度上限 + 内部滚动**，这一稿没定。
- **多选态**：这一稿没碰。真品多选时卡上会出现勾选框，展开的卡与带子也要能勾选。
- **本机 / 云端徽标**：真品的 `assetBadge`（`assets.js:437`）**只在设置页开关打开时才画**。
  这一稿默认画 —— 「这条字节在本机还是只在平台上」是资产库最要紧的一句，
  不该藏在设置开关后面。
