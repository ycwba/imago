# 导演台 —— 布局重构稿「同一副骨架，内部重排」

> 这一稿**只出稿子，没有动产品代码**：`web/` `server/` `tools/` `tests/` 全部原样。
> 新增文件全在 `design/director-layout/` 下面，这个目录**不进运行时**（`shell.html` 不引用它）。
>
> 稿子是**浅色**的。夜间版**不用另设计**：令牌直接取产品那一份
> （`web/styles/tokens.css`），深色档就是**同一个稿子切 `data-theme="dark"`** 派生出来的 ——
> `shots/04-生成态-深色-1440.png` 就是这么渲的（不是另画的一版）。

---

## 0. 这一稿的前提：骨架不动

要求是「**保持原来那个结构整体**」。所以这一稿**没有换骨架**：

```text
页头（导演台 / 项目 / 保存 / 导出）
┌────────┬────────────────┬──────────┐
│ 左栏    │ 中栏            │ 右栏      │
│ 分镜    │ 看片台          │ 这一镜    │
├────────┴────────────────┴──────────┤
│ 轨道坞（剪辑态才有）                       │
└─────────────────────────────────────┘
```

改的是**每一块内部怎么排**。真品里这三块是三份独立的东西（`engine/mid.js` 看片台、
`engine/panel.js` 这一镜、`engine/voice.js` 声音栏、`engine/lanes.js` 轨道），
它们各自长成了自己的样子，彼此没有共同语言。这一稿做的是：**让四块说同一种语言**
（一把尺、一套行名、一次性的动作位置）。

## 2. 改了什么（十二条）

### 2.1 页头：模式开关提上来 + 加一枚时码

- **模式开关原来在中栏顶上**（`engine/mid.js:231`，`顺序 / 剪辑`）。要找它才知道自己在哪个模式，
  而且它长在中栏里，看着像「这一栏的开关」而不是「整页的模式」。
  现在提到页头，改名**顺序 / 剪辑**（= 生成态 / 剪辑态），两态在页头就能分。
- **页头加时码** `00:00:04:05`（HH:MM:SS:FF，等宽字）。这一页以前只有「全片 0:12」一个数，
  回答不了「现在在哪」。时码是剪辑片的通用语言，导演台没有它，是这一稿最明显的缺口。

### 2.2 左栏：镜行两行化 + 底部常驻坞

- **镜行改两行制**：上行 = 两位编号 + 镜名 + 状态点（谁在生、谁成了、谁挂了）；
  下行 = 16:9 缩略图 + 时长 + 候选条数。
  原来缩略图是正方形小格挤在右边，文字被挤成两行（「新镜头 / 已选用 -0…」就是这么来的）。
- **状态用点 + 词**：`已选用 / 待选用 / 生成中 / 生成失败 / 待写描述` 五种，色点 + 词，不再靠整块底色。
- **生成坞常驻左栏底部**：估价（可生成 N 镜（M 条）· 预计 ¥）+ 进度 + 主按钮。
  列表再长，提交按钮也不下沉。
- **剪辑态左栏底部换成「历史编辑记录」**：那块原来是塞在分镜列表下面的折叠区
  （`engine.js:2495`），一展开就把列表挤掉一半。现在它在同一个位置（列表下方），
  是三行摘要 + 「3 步可退」，不压列表。

### 2.3 中栏：候选带的动作长在卡上 + 全片带常驻且按秒成比例

- **候选动作移到卡上**：原来「✓ 用这条 / × 取消选用 / 锁定 / 删除」是播放器下面**单独一行**，
  而你在看的是「第 2 条候选」—— 动作与它作用的东西是断开的。
  现在这三颗压在**当前那张候选卡**的画面上（悬停/选中即现），翻条器
  （展开 / 上一条 / 1 / 2 / 下一条）收到卡片右边。
- **全片顺序带常驻**，并且**按秒成比例**：一镜一格，格宽 = 该镜时长（2.4 秒的镜比 4 秒的镜窄）。
  片子多长、哪一镜在哪，**宽度本身就是答案**。换场插一枚竖排的场次签
  （「场 1 · 雨夜街口」），把竖排分镜表里那层「场」的信息留住。
  原来这根带子要点「顺序」模式才出现、每格等宽，看不出节奏。

### 2.4 右栏：表单 + 常驻提交坞（生成态）

- 生成态右栏原来是一条**要滚的竖表单**，生成按钮沉在最底（改一个参数要滚到底才够得着），
  表单中间还插着第二颗「按描述生成这一镜的画面」（`panel.js:1659`）—— 与底部主钮重复。
- 现在：**表单区可滚 + 提交坞常驻底部**：「✓ 可以生成」+ 估价 + 「生成这一镜（N 条）」。
  两颗生成按钮合并成一颗（重复的那个在落地时删掉，见 §5）。

### 2.5 右栏：六页签 → 竖排四段（剪辑态）

- 原来剪辑态右栏是**一排六个中文页签**（`voice.js:376`）：
  `这一段画面 / 这一镜上的配音 N / 音量与倍速 / 台词 / 生成配音 / 字幕`。
  「这一镜上的配音 N」一个就占掉三分之一宽，六个挤在一行。
- 现在是**竖排四段**：**画面 / 配音 / 台词 / 字幕**。
  段名与底部轨道的行名**同序同字** —— 右栏往下滚，轨道左列往下看，是同一套名字。
  「音量与倍速」并进配音段，「生成配音」并进台词段。

### 2.6 这一镜的轨道上提到中栏；底部坞只留全片

- 剪辑态里「你在中栏看这一镜，它的轨道却在页面最底」—— 视线要上下跑一趟。
- 现在**这一镜的轨道（画面 / 配音 / 字幕三行）上提到中栏**，紧贴画面台下方。
- 底部坞原来的「本镜 / 全片」两档是**同一套行的两个范围**，现在各归各处：
  本镜在中栏，全片在坞里。坞不再需要「本镜 / 全片」开关。
- **剪这一镜的工具跟着这一镜走**：切开 / 向左切 / 向右切 / 删掉 / 融合
  现在在中栏「这一镜的轨道」那一行上（原来在页面最底的坞里：剪的是中栏那一镜，按钮却在脚下）。

### 2.7 入出点就地化

- 坞底原来压着一整句：`正在调这一条候选剪成 N 段，正在调第 N 段…：保留片段 从 [ ] 到 [ ] 秒 [应用]`
  —— 一句话里塞了状态、动作、两个输入框，**读起来不像控件**。
- 现在它是轨道上那一段下面的一条 **trim 条**（两端把手 + 起止秒数），改哪里就在哪里看得到。

### 2.8 时码尺与播放头：一把尺

- 轨道尺原来只有顶部一道，轨行里没有刻度参照。
- 现在尺与轨行**共用一把尺**（同一 px/秒、同一左列宽），**播放头贯穿四行**。
- 底部读数行从两个数变成三格：**插针 / 本镜 / 成片**。

## 3. 签名件：一把尺

这一稿的记忆点是**「同一个位置，在任何一块里都是同一个数」**：

| 出现处 | 是什么 |
| --- | --- |
| 页头 | 时码 `00:00:04:05`（等宽字） |
| 中栏底部全片带 | 按秒成比例，格宽 = 时长 |
| 底部轨道尺 | 与轨行共用同一 px/秒 |
| 底部播放头 | 贯穿四行，同一个 x |
| 读数行 | 插针 / 本镜 / 成片 三格 |

等宽字是时码的唯一正确字体（数字不跳位）。产品令牌里现在没有等宽字体，
这一稿用 `demo.css` 里的一枚**提案令牌** `--font-mono` 顶着。

## 6. 要拍板的事

1. **顺序带按秒排布，短镜会不会挤没了？** 这一稿给了一个 56px 的最小宽度 ——
   给了最小宽度，这根带子就不再严格等于时间。0.5 秒的镜到底要窄成什么样？
2. **两颗生成按钮合并成一颗，行不行？** 落地时删掉表单中间那颗
   「按描述生成这一镜的画面」，还是它有别的用（例如「只重生成画面、不动候选」）？
3. **右栏四段与轨道行名同名，会撞吗？** 同一屏里会同时出现两个「画面」
   （右栏那一段 + 轨行左列）。要不要给右栏加前缀（「这一镜 · 画面」）？
4. **历史编辑记录做成什么样？** 这一稿只画了三行摘要 + 「3 步可退」。
   真品里它是可以点的（点一行退到那一步），这一点没画。
5. **`--font-mono` 进不进 tokens.css？** 时码、镜号、读数都要它。
6. **底部坞现在只有「全片」一档，播放头只标全片位置** ——
   「本镜」的播放头（这一镜里的第几秒）还要不要？这一稿里那一镜的时间
   由中栏的轨道尺承担。

## 7. 这一稿没解决的

- **拖拽排序没做**：顺序带与轨道块的换位（拖）只是示意，样子对，行为没实现。
- **源秒 / 成片秒两把尺**：这一稿的「这一镜的轨道」用的是**这一镜自己的秒**，
  底部全片轨道用的是**成片秒**；字幕块按成片秒落在这一镜范围内时折回镜内秒。
  真品里字幕数据是**候选源秒**（AGENTS §9.2），换算口径要在落地时对齐。
- **手机形态没做**（900px 以下只做到单列堆叠）。
- **导出那一排还是普通按钮**，没有表现「导出中 / 取消渲染」那套状态。
- 右栏的字段集仍是**示意**：真品由 `Capabilities` 声明驱动，
  这一稿没有碰那一层（`型号与时长` 那一组是照着声明的样子摆的）。
