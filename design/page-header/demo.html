01

改造前：七个页面，七种页头

七个页面都有「我叫什么、我在哪、我能干什么」这三件事，但它们分别坐在七个不同的地方： 标题藏在侧轨里（素材库）、缩在左栏顶部（工作台）、随文档滚走（设置）、 单独一套深底 header（导演台）。切页时页头的高度、位置、图标、有没有副标题、有没有动作区全在变 —— 页面身份是整页的事，不该由某一栏来承担。

02

统一后的契约：一条通栏横带

每个页面顶端一条跨页宽、粘顶的横带，横带里按四个槽排： 身份（图标铭牌 + 标题）→ 上下文（计数 / 状态 / 当前项目）→ 说明（一句话：这页在干嘛）→ 动作（页面级动作，最多三个）。槽位按需留空，位置不挪。

A

身份

.phead-id

26px 强调色铭牌方块 + 20px 标题。每页都有：铭牌是全站唯一被强调色着色的元素，也是这一套页头的记号。

B

上下文

.phead-meta

这一批东西现在怎么样 —— 计数、状态、当前项目。资产库的「在制 / 失败」就落在这里，导演台的项目切换也落在这里。

C

说明

.phead-sub

一句话说这页在干嘛，超出省略。收藏页补上「你自己收起来的产物」，切页时不用再猜。

D

动作

.phead-acts

页面级动作，最多三个：刷新、多选、新建。筛选与视图切换不进页头，它们留在下面那行工具条。

四条硬规则

  • 横带跨页宽、粘顶上下留白 13+11 加铭牌 26 = 50px（与侧栏顶行 58 同一量级），sticky 到视口顶。滚到一半，标题还在原地 —— 切页不再丢名字。
  • 图标必有，且只有一种画法26px 方块、6px 圆角、强调色淡底 + 强调色图形、图形 15px。原来收藏是裸星、资产库没图标，现在统一。
  • 标题只说一次页面名只出现在横带里。素材库左轨不再重复写「素材库」——那里改成当前分组（角色 / 场景 / 道具）。
  • 动作分家页头放「这一页能干什么」，下一行工具条放「怎么看这一页」。收藏的「多选 / 上传」从筛选行提到页头，筛选行只留筛选。

样式草案（将来落进 ui.css 公共层；此处只作演示，未落盘）

取值全部来自 tokens.css；不写兜底值、calc() 里用 var()、透明度只走 --a-* 阶梯。 

/* 壳的 --shell-px 只管左右（.page-shell 声明），页头自己给上下留白 */

  position:sticky; top:0; z-index:20;
  background:var(--bg); border-bottom:var(--hair) solid var(--line); }

  background:var(--acc-tint-10); color:var(--acc); }
.phead-h1  { font-size:var(--fs-20); font-weight:700; margin:0; white-space:nowrap; }
.phead-sub { font-size:var(--fs-12-5); color:var(--sub); flex:1 1 auto;
  overflow:hidden; text-overflow:ellipsis; white-space:nowrap; }

  background:var(--panel2); font-size:var(--fs-12); }

03

统一后：七页共用这一条

下面每一块都是一个「页面视口」，可以在里面滚 —— 滚一下看标题栏是否钉在顶上。 七页的横带位置、高度、图标、间距完全一致；变的只有槽位里装了什么。
