# 实施-2026-11-21-润色双稿与双语存显

## 目标

AI 润色对齐拾帧「H3 规范优化」的双稿行为：一次调用输出「主稿（填入提示词）+ 对照稿（对照阅读）」，语言不写死、由 Skill 正文按内容决定；两稿随任务 / 候选保存本地；任务卡、灯箱详情等显示位置默认显示中文提示词、可切换查看英文。

## 范围

- 润色链：工作台三档（视频 / 图片 / 配音）、导演台单镜、导演台「润色全部文案」、导演台配音行润色、「按这句再改」（follow）。
- 存显链：PromptLog 归档（md + `_index.json`）、工作台任务与草稿、导演台候选与配音草稿、`submitCandidate` 归档、任务卡 / 详情 / 灯箱 / 资产库卡 / 收藏。
- 不动：拾帧「H3 规范优化」按钮本体（其结果经同一套存显）；提交给平台的请求体（只发主稿）；导演台编辑器 / 剧本视图 / 拖拽载荷（维持主稿）。

## 设计要点

- 标记约定：主稿结束后单独一行 `【对照稿】`（全角括号四字），随后对照稿正文。找不到标记 / 主稿为空 / 中途停止 → 整份当主稿（单稿回退，兼容旧 Skill 与纯朗读稿）。
- 切分器唯一实现 `web/domain/polish-bi.cjs`（UMD 双模式：浏览器挂 `window.PolishBi`，Node 供判据 require）；`TextAI.splitBi` / `TextAI.biStream` 只转发。
- 语言标签 `'zh'` / `'en'`（字符串，可扩）；主稿语言随技能定：视频 `en`、图片与配音 `zh`；H3 主稿固定英文。显示层默认渲染中文那份。
- 配音条件双稿：纯朗读正文 → 单稿原语言；带风格描述 / 背景描述 → 双稿，且对照稿里**说话部分保留原语言逐字照抄、不翻译**。
