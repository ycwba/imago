## 目标

修掉用户实机报错 `Uncaught ReferenceError: Cannot access 'syncPromptBack' before initialization (studio.js:243)`。
这是上一批「批注图重构」（`a488abd`）引入的**启动期连锁错误**，不是 `syncPromptBack` 本身写错。

## 根因（先用浏览器判据复现，不猜）

真实堆栈（三种路由 `#studio.html` / `?t=image` / `?t=audio` 一致）：

```
TypeError: Cannot read properties of undefined (reading 'inputs')
    at restoreAnnotatedSlots (web/pages/studio.js:332)
    at runPage (web/pages/studio.js:345)
```

链条：

1. 批注重构在 `runPage()` 顶层第 345 行同步调用了 `restoreAnnotatedSlots()`。
2. 该函数读 `cur().inputs.image`；而 `cur() = ST[TYPE]`，`TYPE` 要到 `boot()`（第 3913 行）
   才被赋成 `video/image/audio`，此刻仍是 `''` → `ST['']` 是 `undefined` → 读 `.inputs` 抛错。
3. `runPage()` 从这里整段中断，后面的 `const syncPromptBack`（1732 行）、`window.setType`（4014 行）
   等都**没执行到**。
4. 但类型切换按钮的 click 监听在 253 行**已经绑好**，用户一点击 → `setType()` → 第 243 行
   `syncPromptBack()` → 该常量还在暂时性死区 → 用户看到的 `Cannot access ... before initialization`。
