# 批注编号重排、重开自动恢复与「补一句」下线

## 目标

- 删除任一条编号批注后，右栏列表与图上编号立刻顺次重排（永远 1..N），产物 PNG 与文档同步用新号。
- 批注完成后（或直接关灯箱）再打开同一条目，批注编辑层自动恢复原状 —— 不再偶发「只有原图没有批注」。
- 下线「+ 补一句」：按钮、隐藏输入框、`doc.note` 字段与相关文案、判据一并删净。

## 根因

- 编号不重排是上一批的取舍（「编号只增不复用」），按用户要求改为删除即重排。
- 重开丢批注是时序缺陷：`Wb.lightbox.show()` 异步补图，而 `__spaLoadScript` 对已缓存的脚本
  立即 resolve，第二次起 `LbMask.enter` 会跑在图片加载前面，撞上「img 未就绪」当场退出
  （本地 blob 地址每次打开都是新地址、必中；http 地址首开也中）。

## 范围

- `web/ui/lb-mask.js`：删除即重排；`enter` 改为等图就绪再起层（有界轮询，灯箱关掉安静作废）；下线补一句。
- `web/styles/ui.css`：删 `.lb-ann-add` / `.lb-ann-note` 两行样式。
- `web/domain/text-ai.js`：`readAnnots` / `annotText` 去掉 `note` 字段（旧文档里的 note 读入时丢弃）。
- `tests/e2e/ref-view.cjs`：⑥ 改验重排；⑧ 改为复刻真实时序（脚本已缓存 + 不等图直接 enter）；
  补一句断言删除。
- `tests/text-ai-media.mjs`：批注文档样例与 `annotText` 断言去掉 note。
- 文档：本文改名「已完成」；上一批实施文档里「删除后不自动重编号」「补一句」两处事实句同步改掉。
