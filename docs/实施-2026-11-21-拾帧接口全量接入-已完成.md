# 拾帧接口全量接入（catalog / ledger / assistant / 配音 / steps）

## 目标

- 消掉「这家没有开放的型号列表接口」提示：三家拾帧 provider 声明 `endpoints.models:'/v1/catalog'`，能力清单来自平台。
- `GET /v1/account/ledger`（消费明细 + CSV 导出）接进用量页。
- `POST /v1/assistant/script`（H3 官方规范优化，含翻译稿）接进工作台视频提示词。
- `h3_ref2v` 的 `voice_audio` / `voice_texts`（平台配音）落成声明驱动字段。
- `steps`（生成质量，catalog 新披露）落进 h3 视频高级字段。

## 范围

- `server/registry-config.js`：三张 provider 补端点声明，`REGISTRY.version` 26 → 27。
- `server/providers/validate.js`：新声明字段校验（`modelsGrow` / `promptTools` / `ledger` / `create.voiceDub`）。
- `server/routes/capabilities.js`：`modelsGrow:false` 时只回声明内型号（回包 152KB → 只留 12 行）。
- `web/domain/capabilities.js`：`NORM_SHAPES.shizhen` 归一化 + `apply()` 尊重 `modelsGrow:false`。
- `web/domain/api.js`：`createBody` 的 `voiceDub` 折算；`sctx` 带 model（`only.when.model` 生效）。

- `web/pages/studio.js` + `tools/vue-templates/studio.html`：视频台「H3 规范优化」按钮与接线；`topBoolCtx` 带 model。

回包形状（实测锁定）：

- catalog：`{models:[…30 行], composer_models, routed_endpoints}`；行 = `{id, kind, stage, web_available, input_slots[], params[], duration{min_seconds,max_seconds,default_seconds,…}, quality_tiers{tiers[{name,cny_per_second}], aspect_ratios[], default_quality, default_aspect_ratio}, pricing{…}, note, notice, execution_variants}`。h3 视频 params 有 `steps`（int 1–12，template_default 6）与 `width/height`（本次不接，画幅仍走 quality×aspect_ratio）。
- ledger：`{from, to, timezone, balance_cny, totals{spent_cny, added_cny, lines}, lines[{id, time, ts, category, type, amount_cny, balance_after_cny, job_id, endpoint, model, source, quality, video_seconds}]}`。
- assistant：POST → 202 `{task_id, status:'running', poll_url:'/v1/assistant/script/<id>', retry_after_seconds:5, idempotency_key}`；轮询 → `{status:'succeeded', draft{…}, draft_text（中文稿）, draft_en（英文正式稿）, translated, mode, billing…}`；幂等键在体里（复用 create.idempotencyBody 通道）；免费。

功能验收：

- 打开工作台/设置页拾帧账号：能力来源显示「能力来自上游接口」，不再出现「这家没有开放的型号列表接口」。
- 用量页拾帧卡：消费明细面板能按日期查出 lines（实测 2026-11-14~21 有 5 条），CSV 能下载。
- 视频台选 H3 型号：出现「H3 规范优化」，一键改写后提示词替换为英文正式稿，中文稿可展开参照。
- `h3_ref2v` 上传参考音频：高级设置出现「平台配音」开关；开启后原始请求里 `params.voice_audio:[1,…]`；填了「声音原话」则 `params.voice_texts:{"1":…}`。
- h3 视频高级设置出现「生成质量」数值框（1–12）。

## 风险与不做

- catalog 里另有 18 个未声明型号（`film_assemble` / `hunyuan15_i2v` / `krea2_*` / `_base` 变体等）：不在用户给的文档表里、下单形状未实测，`modelsGrow:false` 挡住不进下拉；平台真要开放时补声明即可。
- `h3` 视频 catalog 的 `width/height`（64–4096, 32 倍数）与现有 `quality×aspect_ratio` 画幅体系重叠，语义未实测（是否覆盖/冲突），本次不接。
- `healthz` 不在文档接口表内，不接；型号关闭由下单时平台报错兜底。
- assistant 免费但走 relay 密钥注入；轮询上限 3 分钟，超时按失败提示可重试（同幂等键不重复扣）。
