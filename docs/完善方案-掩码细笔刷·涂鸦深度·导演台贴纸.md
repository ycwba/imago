## 1. 掩码细笔刷（B16-1）

### 1.1 现状与根因

- `web/ui/ref-view.js:18`：`BRUSH = [[0.02,'细'],[0.045,'中'],[0.09,'粗']]`；
- `:154-156`：`lw = BRUSH[state.w][0] * Math.min(cv.width, cv.height) * 2`，地板 `Math.max(2, lw)`。
- **根因就是那个 `×2`**：比例本意是「占短边的比例」，乘 2 之后变成了直径占比的两倍——
  最细一档在 1024 掩码画布上是 `0.02 × 1024 × 2 ≈ 41px`。圈一只眼睛、描一条细边都不够用。
- 自绘光标（`moveGhost`）用同一条公式算直径，改系数两处自动一致。

### 1.2 改法

| 档 | ratio | 1024 画布实际直径 |
|---|---|---|
| 极细 | 0.006 | ≈ 6px |
| 细（默认） | 0.012 | ≈ 12px |
| 中 | 0.025 | ≈ 26px |
| 粗 | 0.05 | ≈ 51px |

- `BRUSH = [[0.006,'极细'],[0.012,'细'],[0.025,'中'],[0.05,'粗']]`，公式去掉 `×2`：
  `lw = Math.max(2, BRUSH[state.w][0] * Math.min(cv.width, cv.height))`（比例即直径占比）。
- 默认档下标保持 1（「细」）——现状打开就是细，用户无感升级，只是真的细了。
- `Math.max(2, …)` 地板保留：掩码最长边 1024，6px 已远高于地板。
- 「清此色」按色距 <60 擦除，与笔宽无关，不受影响；导出 / 回显路径不碰。

### 1.3 验收

- 1024 图上「极细」能圈住五官细节，导出 PNG 里笔迹宽 6px ± 2；
- 光标圆圈直径与实际笔迹一致（两处同公式）；
- 探针（常驻 e2e 或一次性）画一笔极细，量像素宽断言 ≤10px。

## 2. 涂鸦的图片界面加大（B16-1 同批）

### 2.1 现状

- `web/styles/ui.css:1028`：`dialog.ui-dlg { max-width: min(560px, 92vw); … }`——全站弹窗一个帽，
  掩码编辑在 560px 弹窗里画 1024 的图，显示约 528px，落笔换算两倍还多；
- `:1700-1701`：`.rv-stage img/video { max-height: min(56vh, calc(var(--sp-64) * 8)) }`（512px 第二重帽）。

### 2.2 改法

- `UiDialog.open` 本就支持自定义 id（`web/ui/forms.js:1343` `dlg.id = o.id || 'uiDlg'`）——
  `ref-view.js` 的 `UiDialog.open({ id: 'rvDlg', … })`，CSS 按 id 放宽，不动全站弹窗帽：

  ```css
  dialog.ui-dlg#rvDlg { max-width: min(1200px, 96vw); width: min(1200px, 96vw); }
  #rvDlg .rv-stage img, #rvDlg .rv-stage video { max-height: min(72vh, calc(var(--sp-64) * 14)); }
  ```

  （`--sp-64 × 14` = 896px；1440 宽的窗里图片显示宽可达 1100+，窄窗 96vw 不破。）
- 编辑态工具条已吸底（`.rv-bar.is-edit`），大弹窗下直接受益，不需要另改。
- 音频 / 视频查看同批受益（同一弹窗 id）。

### 2.3 验收

- 1440 宽窗：图片显示宽 ≥ 1100px；760 窄窗：不超出、工具条不换行到 4 排以上；
- ui-visual 48 画面不受影响（RefView 不在基线里）；token 体检 0 裸值。

### 2.4 落点

| 文件 | 改什么 |
|---|---|
| `web/ui/ref-view.js` | `UiDialog.open({ id: 'rvDlg', … })` 一处 |
| `web/styles/ui.css` | 追加两条 #rvDlg 规则 |

## 3. 深度可调的 3D 涂鸦（B16-2）

### 3.1 现状

- 所有笔迹落在**一个**参考深度面上：`view.js:633-642 sketchPoint` 与「过焦点、法线=视线」的平面求交；
  焦点来源 `:622-631 sketchFocusPoint`（选中实体中心 → 活动机位 target → orbit.target）。
- 同一角度下没有「画远一点 / 近一点」的手势——想给背景和前景各画一笔，只能转视角。
- Alt 起笔（`:747-756`）已经会取模型表面交点，但只影响第一个点，后续点仍回深度面。
- 圆 / 矩形在相机 right/up 平面内展开（`:644-667 strokePoints`），**天然兼容任意位置的同向平面**——
  深度面挪远挪近，这两个工具不用改。

### 3.2 语义设计：三种取深

| 档 | 取深 | 用途 |
|---|---|---|
| 自动（默认） | 现行为：焦点面 | 大多数「对着主体画」的场景 |
| 定距 | 面 = 相机沿视线方向推 `d` 米（`d` 由滑杆 / 快捷键给，0.2–30m） | 同一角度给前景 / 背景分层画：拖一下滑杆再画，层就不一样 |
| 贴面 | 每个采样点 = 射线与场景网格的交点（照 `:742-747` 的 hit 逻辑，跳过 LineSegments） | 画在模型表面起伏上；同一角度里远近随表面自然变化 |

- `marks` 仍是世界坐标 → `screenToCamPaths` 换算、契约、AI **全部不用动**（深度只是落笔手段）。
- 「贴面」档打不中（空白处）退回自动面；圆 / 矩形以第一命中点为面锚（法线仍取视线）。
- Alt 起笔保留：定距 / 自动档下按住 Alt 单点取表面。

### 3.3 交互

- 涂鸦条（`model.js:2644-2705 paintSketchBar`）加一组「深度」控件：
  「贴面」开关 + 距离滑杆（0.2–30m，步 0.1，自动档禁用）+ 读数（`自动` / `x.xm` / `贴面`）。
- 快捷键 `[` / `]`：涂鸦开着时距离 ±0.25m（贴面档无效）。
- 状态：`st.sketch.depth = { mode: 'auto'|'plane'|'surface', dist: number|null }`——页面态，
  与 `sketch.tool / color` 同族（不进 doc，刷新即失，与标注生命周期一致）。
- 经 `view.setSketch({ depth })` 传入；`view` 侧读数 getter `getSketchDepth()` 供滑杆回显。

### 3.4 落点

| 文件 | 改什么 |
|---|---|
| `web/model3d/view.js` | 状态字段；`sketchPoint` 按档分流（自动 / 定距面 / 贴面 raycast）；`setSketch` 收 depth；`getSketchDepth()`；贴面档的圆/矩形面锚 |
| `web/pages/model.js` | 涂鸦条控件 + `[` `]` 键（并入 `onSketchKeydown` 的激活守卫内）+ 深度读数回显 |
| 契约两份 | **不动**（marks 语义没变） |

### 3.5 已知取舍（写进代码注释）

- 橡皮 `eraseNear` 半径固定 0.25 世界单位（`view.js:671`）——远层上视觉半径偏小，接受；
  顺路优化（悬停高亮候选标注）在本文件 §3.6 的二期里。
- Shift+滚轮调深度**不做**：OrbitControls 的 wheel 监听注册在前，抢不到优先级，滑杆 + 快捷键够用。
- 贴面档性能：每个采样点一次 raycast（只对 `content.group`），与拾取同量级，无碍。

### 3.6 验收

- 同一角度：拖滑杆画两笔（近 / 远），转 90° 看两笔明显分层；
- 贴面档在模型正面画箭头，笔迹贴着表面起伏；空白处退自动面；
- `[` `]` 微调读数跟着变；蓝线照旧换算出 camPath（`model3d-sketch.mjs` 不动全绿）；
- 探针：贴面档对固定盒子画一笔，断言采样点 z ≈ 盒面 z。

### 3.7 判据

- 纯部分抽 `planeAt(cam, dist)`（定距面锚点）与「hit 退自动面」的分流函数进可测文件，
  `tests/model3d-sketch.mjs` 加 3–4 条；交互（滑杆 / 键）进一次性探针。

## 4. 导演台贴纸（B16-3）

### 4.1 语义

**贴纸 = 叠在成片画面上的图片层**（透明 PNG 最佳，不限）：有起止时间（成片秒）与画幅内
位置 / 大小 / 透明度，预览与导出都烧进画面。它是纯视觉装饰——**不进 AI 契约、不进 FCPXML**
（FCP 没有通用图片 overlay 轨；成片已烧入，导出回执注明）。

### 4.2 数据（项目级，不进镜头）

```json
"stickers": [
  { "id": "st-1", "name": "帽子.png", "src": "/asset/la_xxx",
    "x": 0.62, "y": 0.10, "w": 0.25, "h": 0.25,
    "t0": 3.0, "t1": 8.5, "opacity": 1, "z": 0 }
]
```

- 挂 `p.stickers[]`（成片级 overlay，与镜头无关）；坐标相对画幅 0–1（导出分辨率无关）；
- `src` 只认两种「记得住的」写法：`data:` 与 `/asset/<id>`——**照抄 sanitize 对 `sc.img` 的同一道闸**
  （`engine/sanitize.js:52` 一带：blob: 刷新即失效、/getv 签名一天 403，都算坏值抹掉）；
- `sanitize()` 补一段归一化：数组存在性、字段 clamp（x/y/w/h ∈ [−0.5, 1.5]，w/h ≥ 0.02，
  t0/t1 ≥ 0 且 t0 < t1，opacity ∈ [0,1]，z 整数）、数量不设上限；
- 撤销不用改：workspace 快照是整份 JSON，`stickers` 自动进 undo 栈与 `dir_ws_unload` 救生包。

### 4.3 入口：统一文件选择器

- 时间线工具条加「贴纸」按钮 → `AssetPicker.open({ types: ['图片'], multiple: true,
  upload: { accept: 'image/*' }, title: '选贴纸（透明 PNG 最佳）' })`——与素材槽 / 参考图
  同一份选择器（`web/domain/asset-picker.js`），不另做第二份文件选择 UI；
- 选完每张的默认铺法：居中、宽 = 1/4 画幅（高按图片宽高比）、出现区间 = 当前播放头起 3 秒
  （夹到片长内）；
- 参考现有接线样板：`engine/import.js:233 pickRefMedia`（AssetPicker → 落字段 → renderEditor）。

### 4.4 预览与导出（一份画法，两处消费）

- 新纯件 `web/director/sticker.js`：
  - `activeAt(stickers, t)` → 按 t 过滤 + 按 z 排序；
  - `clampSticker(s, filmDur)` → 时间 / 坐标夹取；
  - `drawStickers(ctx, w, h, list, imgOf)` → 在既有 2D 上下文上按归一化坐标画（`ctx.globalAlpha`、
    `drawImage`），与 `media-export.js:267 drawContain` 的 contain 口径一致；
- **导出**：`media-export.js` 帧循环 `:630-658` 在 `compositeTransition` 之后、`drawCaptions`（:657）
  之前调 `drawStickers`——z 序 = 视频 → 转场 → **贴纸** → 字幕；图片字节走 `loadStill`
  同款解码缓存（顺路吃到 P2-31 的字节缓存修复）；
- **预览**：中栏播放器 / 剪辑态画层用同一份 `drawStickers`（预览 ctx 就是同一个 2D 坐标系），
  屏幕上与片子里的贴纸是同一副样子——与字幕「预览叠层与导出现画对齐」的纪律同款。

### 4.5 时间线（剪辑坞）

- `engine/timeline.js:154-164` 的 rows 聚合已是「imageLanes / voiceLanes / capLanes」三族同形——
  加第四族 `stickerLanes`，lane 上按 t0–t1 画色块区间（点击选中）；
- 一期交互：点击选中 → 右栏数值编辑（t0 / t1 / x / y / w / h / 透明度 / 层序 / 删除），
  预览即见；拖拽改时间用现成 `tl-resize / tl-reorder` 纯件适配，放二期。

### 4.6 工程文件 / 清洗 / 回执

- `projectfile` 导入导出是 JSON 透传，`stickers` 自动跟随（实施时核对它有没有字段白名单，
  有则补一行）；`sanitize` 归一化见 4.2；片长变化（贴片 / 删镜）后 `t1 > 片长`：渲染侧 clamp
  + sanitize 归位，不弹错；导出回执注明「贴纸只烧在成片里，FCPXML 不带」。

| 文件 | 改什么 |

### 4.8 分期

- **一期（本批）**：数据 + 入口 + 预览 + 导出 + 数值编辑 + 删除 + 判据；
- **二期**：时间线 lane 拖拽改时间 / 拉边、旋转、不透明度关键帧、贴纸收藏夹（常用表情免重选）。

### 4.9 风险

- 贴纸 src 若是本地上传且从未入资产库，字节只在会话里——入口处落盘走 AssetTransfer
  （与参考图同一套「/asset/ 引用」纪律，避免 sanitize 抹掉后「贴纸消失」）；
- undo 字节：src 是引用不是 dataURL，快照涨幅有限（24MB 撤销帽不用动）；
- AI 不感知贴纸：不进契约、不进提示词，分镜 / 台词各 Skill 不需要知道它存在。
