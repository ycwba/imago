## 一、新发现的 bug（全部已修）

**P0-1 [掩码] 灯箱化重写把「等图片解码完」这道等待删了：画布按 1×1 定尺寸且永不重定——掩码整条链路坏**
- 位置：`web/ui/ref-view.js`（重写后 `img.src` 赋值后同步进编辑态，`fitCanvas` 读 `naturalWidth || 1`）。
- 触发：任意一处「点开看」打开一张图片。
- 后果：画布 1×1 → 一笔涂满全图 → 「完成」把垃圾掩码存回条目发给文字 AI，已存掩码也会被覆盖。
- 修法：`img` 挂 `load`（顺带 `decode()` 预热）之后才让编辑器起作用；本探针当场量出「细=14px、极细=8px」证归位。

**P1-1 [导演台] Ctrl+Z / Ctrl+Y 在任何页面都作用于导演台**：模块级 document 监听无页面激活守卫
（对照 model.js 批一的同族修法与 edit.js 的 isConnected 守卫——同一族只有这一份漏）。已加
`window.__spaActivity.visible('director.html')` 前台判断。

**P1-2 [掩码] 编辑中按 Esc 直接关窗丢笔画**：`hooks.ctl` 在 openMaskEditor 里从未被调，
`editorCtl` 恒 null → 丢弃确认的握手断在一半。已补 `hooks.ctl({ dirty, leave })` 接线。

**P1-3 [导演台] 标记面板标题 / 备注 / 起点 / 止点逐键重画整个面板**：`input` 与 `change` 都派给
`onPanelInput` → 每敲一个字 commit 一次（撤销栈逐字灌满）+ panelPatch 整片重画 → 焦点回 body、
第二个字落在 document 快捷键上（标题带 `m` 凭空建标记）。已改为只认 `change`（失焦落账）。
