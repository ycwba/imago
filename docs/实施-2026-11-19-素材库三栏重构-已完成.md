# 实施-2026-11-19-素材库三栏重构

> 状态：已完成

## 目标

完全颠覆素材库页面的交互模型：从「两栏 + 检查器 + 整屏详情层」的三层结构改为
**三栏主从**——目录轨 + 卡片网格 + 右侧常驻素材面板，点卡即选中、选中即编辑。
让「看一条素材」只有一个地方，让高频动作（出图 / 试听）上卡面，让编辑内容分区单列。

## 范围

- 交互骨架：`tools/vue-templates/chars.html` + `web/styles/spa-chars.css` + `web/styles/tokens.css`。
- 页面逻辑：`web/pages/chars.js` 接线调整；`web/pages/chars/detail.js` 删除，
  逻辑移植进新的 `web/pages/chars/pane.js`（分区单列面板）。
- 卡面增强：hover 快捷动作条（出图 / 试听 / 删除）+ 状态徽标（候选数 / 声音方式）。
- 助手快照 `web/core/page-context.js` 的 chars 段。
- 判据与基线：`tests/selfcheck.cjs` §8、`tests/e2e/viewport-clicks.cjs` CHARS 组、
  视觉基线 chars 4 档。
- 文档：`CHANGELOG.md` 新批次条目、本文件。

**不动**：`web/domain/chars.js` 数据层全部签名与 data-act 协议、`char_lib` 数据形状、
批量条位置与五件事、目录轨（类型 + 分组）、搜索 / AI 挑选 / 分页 / 灯箱 / 拖拽载荷、
`char_pending` 任务认领、改名回填双路落盘、`wb:char-pic` 等事件契约、opts 固定 9:16。
