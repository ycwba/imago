# 接入供应商「拾帧」（shizhenvideo.com）

## 目标

- 三档能力各一张 provider，共用一张账号卡（`keyId: 'shizhen'`）：
  - 视频 4 型号：`h3_t2v` / `h3_i2v` / `h3_flf2v` / `h3_ref2v`
  - 图片 5 型号：`zimage_first_frame` / `h3image_t2i` / `h3image_edit` / `qwen_edit` / `firered_edit`
  - 音频 3 型号：`acestep_bgm` / `tts_voice_design` / `tts_dialogue`
- 全链路：上传素材 → 下单 → 查状态 → 取 `pickup_url` → 下载 / 自动存本机。
- 报价走平台接口（¥），余额进侧栏（`balance_cny`）。
- 语音工作台新增两种「音频方式」：背景音乐、分句配音（按 API 声明驱动，不写死平台）。

## 范围

- `server/registry-config.js`：三张 provider，`REGISTRY.version` 25 → 26。
- `server/providers/validate.js`：新声明字段校验。
- `server/routes/relay.js`：raw 上传读体上限。
- `web/domain/api.js`：幂等键进体、retrieve、报价 / 余额、尺寸字段、素材次序。
- `web/domain/asset-transfer.js`：raw 上传。
- `web/domain/assetlib.js`：报价金额字段与嵌套体。
- `web/domain/gen-forms.js` + `web/pages/studio.js` + `tools/vue-templates/studio.html`：图片任务号、音频异步与模式声明。
- 文档收尾：`.env.example` / `CHANGELOG.md` / `AGENTS.md`。

## 实测结论（S0）

| 事实 | 结果 | 落到哪里 |
| --- | --- | --- |
| 鉴权 | `Authorization: Bearer <key>` | 现有机制，零改动 |
| 视频下单 | `POST /web-api/jobs`，`{endpoint, duration_seconds, quality, aspect_ratio, params:{prompt,seed…}, input_uris, idempotency_key}` | `create.body` + `nest.params` |
| 图片/音频下单 | `POST /v1/jobs`，`{tier:'A', endpoint, idempotency_key, params:{…}, input_uris}` | 独立 provider + `constants.tier` |
| 顶层 `duration_seconds` | 只给视频；音频/图片的时长在 `params.duration_seconds` | 两套 `nest` |
| 幂等键 | 在请求体 `idempotency_key`，不是请求头 | `create.idempotencyBody` |
| 上传 | `POST /v1/uploads`，体是文件本身 + `X-Daipao-Filename`；回 `{uri:'dpupload://…'}`，上限 128MB | `create.upload.style='raw'` |
| 查状态 | `GET /v1/jobs/{job_id}` → `{job_id, endpoint, status, request_snapshot.params.prompt, output_media, …}` | `list.map` 点路径 |
| 取结果 | `GET /v1/jobs/{job_id}/result` → `pickup_url`（1 小时签名）+ `ready`/`retry_after_seconds` | `retrieve` + `taskFallback` |
| 列表 | `GET /v1/jobs` 不存在（`unknown_endpoint`） | 历史由本机资产库承担 |
| 报价 | `POST /web-api/quote` → `estimated_cost_cny`（元）/ `frame_count` / `actual_seconds` | `pricing.amountField` |
| 余额 | `GET /v1/account` → `balance_cny` | `balance.style:'field'` |
| 状态词 | `queued/running/succeeded/failed/cancelled/rejected` | 现有判定全认 |
| 视频画质/比例/时长 | 480p/720p/1080p；16:9、9:16、4:3、3:4、1:1；时长区间 0.92–15.08 秒 | `resolutions` / `aspect_ratios` / `durations:[1,15]` |
| 图片尺寸 | `h3image_*` 是 2K/4K × 比例 → `size_presets` 换 `width/height`；`zimage` 自由宽高（16 的倍数） | `create.sizePresets` / `create.sizeFields` |
| 素材顺序 | `input_uris` 按种类先后编号（图 → 视频 → 音频） | `create.inputOrder` |

## 风险与不做

- 回包仍有未实测项：排队中 `/result` 的 `ready:false` 语义、失败单的错误字段名。S2 真跑时以实际回包校准 `list.map.error`。
- 上传体积：平台允许 128MB/个，本地 relay 默认 64MB。S1 只对 `upload.style:'raw'` 这条路径放开到 132MB（内存一次性缓冲）。
- `h3_ref2v` 组合上限：目录只枚举 9 图 + 3 视频（合计 12），文档说还能加最多 3 段音频。声明按文档给到 `reference_audio:{max:3}`，超了由平台 422 拒（不扣费）。
- `h3image_edit` 按图数分档计价（1–3 / 4–8 / 9–16 张），报价体没有「这次带几张图」，估价值只会落在最低档，界面照实带一句「以平台结算为准」。
- 图片档位标签 `AdvParams.label()` 的「· N积分」写死在积分供应商上，拾帧按 ¥ 计价，所以图片也走实时报价、不写 `price` 表。
- 不做：`h3_ref2v` 的 `voice_audio` / `voice_texts` 显式编号；平台其余未开放的 endpoint；`/v1/catalog` 动态清单。
