## 3. 批次 1：高危缺陷 18 条

### R1 资产下载 /asset?dl=1 永远 502 [已核实]
- 位置：`server/routes/outbound.js:95-100`
- 问题：`const { st, h } = passthroughHeaders(ir.headers, { disposition: (!q.get('dl') || st >= 400) ? ... })` 中 disposition 表达式引用尚在初始化的 st（TDZ），带 dl=1 必抛 ReferenceError，外层 catch 回 502。资产库/选择器全部下载按钮不可用。
- 改法：先解构取 st，再单独拼 disposition（或用 ir.statusCode）。
- 验证：routes-smoke 断言 /asset/la_xxx?dl=1 返回 200 + Content-Disposition。

### R2 导出素材取消无效且被报成成功 [已核实]
- 位置：`web/director/engine.js:2440-2444、2563-2575`
- 问题：`exportingAssets` 全文件无一处置 true（仅声明+读取）；`finally { renderCancelled = false; ... }` 之后才 `if (renderCancelled)` 判定，恒 false。取消后照报「素材导完了」。
- 改法：finally 前 `const cancelled = renderCancelled;`；删 exportingAssets，rendering 时点按钮置 renderCancelled=true 并调取消。
- 验证：e2e 导出途中取消，状态行为「已取消」，返回 ok:false。

### R3 镜像索引超上限裁掉最新记录 [已核实]
- 位置：`web/domain/local.js:219-223`
- 问题：`keys.slice(IDX_MAX)` 对插入序（旧到新）取尾部，删的是新记录。索引到 2 万条后新产物刚写入即被裁。
- 改法：`keys.slice(0, keys.length - IDX_MAX)` 删最老；补 `d.a[x] === k` 防串判断。
- 验证：单测塞 IDX_MAX+10 条，断言留下最新 IDX_MAX 条。

### R4 ::ffff: 形式 IPv6 绕过内网闸 [已核实]
- 位置：`server/security.js:46-52`
- 问题：`zero = g.slice(0,6).every(===0)` 后判 `g[6] === 0xffff`，映射地址的 0xffff 在下标 5，分支永不进入，映射内网地址被判公网放行。
- 改法：`zero = g.slice(0,5)`，映射判断改 `g[5] === 0xffff`，字节取 g[6]/g[7]。
- 验证：`isPrivateHost('[::ffff:127.0.0.1]') === true` 进测试。

### R5 型号迁移正序删键隔条丢 [已核实]
- 位置：`web/domain/gen-forms.js:192-204`
- 问题：`for (let i=0; i<localStorage.length; i++)` 内 `localStorage.removeItem(key)`，键前移导致 i++ 跳过下一条。
- 改法：倒序遍历。
- 验证：3 个旧键迁移后全进新键且旧键全删。

### R6 文字 AI 余额解析恒 ok:true [已核实]
- 位置：`web/domain/text-ai.js:1181-1191`（deepseek/moonshot/siliconflow 同型）
- 问题：字段缺失时 amount 折 0 仍返回 ok:true，verifyKey 报「密钥可用」。
- 改法：真读到余额字段才 ok:true，否则 ok:false + reason。
- 验证：`{}` 与 `{"balance_infos":[]}` 断言 ok:false。

### R7 流式失败后盲目改走非流式重发 [已核实]
- 位置：`web/domain/text-ai.js:1030-1032`
- 问题：`/stream_options|unknown|unsupported|extra/i.test(e.message)` 即 `return await this.chat(...)`，got===0 不能证明未受理，可能双份计费。
- 改法：仅首包前明确 4xx 拒收才降级；已建流后如实抛。
- 验证：单测模拟流中断，断言不重发。

### R8 素材库老字典资产 id 每次读取随机 [已核实]
- 位置：`web/domain/chars.js:1892`
- 问题：`id: k + ':' + newAssetId()` 每次读都换新 id，setAssetName/removeAsset/setAssetProps 靠 id 定位失效。
- 改法：id 用稳定值（k 或 k:src 确定性哈希），落盘一次后即列表。
- 验证：连续两次 assetsOf id 一致；改名后能找回。

### R9 无音轨时 BGM 被静默丢弃 [已核实]
- 位置：`server/render-jobs.js:679-690`
- 问题：BGM 混音整段被 `if (aLabels.length)` 包住，纯画面+BGM 时输入加了却不进 filter_complex。
- 改法：`aLabels.length || bgmIdx >= 0` 时单独用 [bgm] 建 [aout]。
- 验证：e2e 纯画面+BGM 渲染产物有音轨。

### R10 CONNECT 隧道无超时 [已核实]
- 位置：`server/outbound.js:96-123`
- 问题：ProxyTunnelAgent.createConnection 只挂 connect/error，无 setTimeout/close 兜底；代理假死时请求永久挂起。
- 改法：`preq.setTimeout(15000, ...)` + close 兜底 finish。
- 验证：假代理端口（accept 后不回 2xx）15s 内报错。

### R11 收藏页翻页后缩略图全空 [已核实]
- 位置：`web/pages/favorites.js:385-389、224、240`
- 问题：pager render 回调只 `pagerTick.value++`，urls 只按当前页重取，thumbHtml 只读 urls。对照 chars.js:1929 是 `render: () => { render(); }`。
- 改法：回调改调真正的 render()，或把取 urls 挪进 watch(pageItems)。
- 验证：新增 `tests/e2e/favorites-pager.cjs`：24+ 条收藏点下一页，断言第 2 页 .thumb 有 img/video。

### R12 429 被标 maybeSubmitted [已核实]
- 位置：`web/domain/api.js:623`
- 问题：429 是限流未建单，却提示「可能已受理先核对列表」，用户被卡在错误方向。
- 改法：429 移出该判据（保留 5xx/408）。
- 验证：单测 429 的 maybeSubmitted 为 falsy。

### R13 POST 200 非 JSON 被判成失败 [已核实]
- 位置：`web/domain/api.js:632-635`
- 问题：parseErr 抛裸 Error，无 status 无 maybeSubmitted，用户重发导致二次扣费。
- 改法：抛错带 status，POST/PUT/PATCH 置 maybeSubmitted=true。
- 验证：单测 POST 200+非 JSON 断言 maybeSubmitted===true。

### R14 生成关键帧无入口重入锁 [已核实]
- 位置：`web/director/engine.js:12410`（函数头）；kfRun 定义 11977、置 true 于 12458
- 问题：入口无 `if (kfRun) return;`（全文件仅 11183 读它），两段 await 后才置锁，期间 renderSoft 重建按钮回可点态，连点即并行双跑，sh.keyframes 互相覆盖、双倍生图扣费。
- 改法：入口加锁 + 模板按运行态渲染 disabled（参照 9758 genOneBusy）。
- 验证：连点两次只发起一轮提交（探针计数）。

### R15 applyTheme 模块顶层裸 localStorage [已核实]
- 位置：`web/director/engine.js:11826-11831`；同类 `11976`
- 问题：模块求值期 `applyTheme(localStorage.getItem('dir_theme') || 'light')`，读写均无 try，隐私/禁存模式抛错导致 engine.js 整模块失败，导演台白屏。违反本文件 7222 自立的「必须包 try」。
- 改法：读写包 try，失败退回 light。
- 验证：禁存环境打开导演台可渲染。

### R16 清空提示词对非草稿候选无效 [已核实]
- 位置：`web/director/engine.js:10983`；取值见 `promptTextOf` 5406
- 问题：点击只清 `d3.prompt`（草稿）或 `sh.prompt`，而显示读的是 c.prompt 优先，提交过的候选清不掉。
- 改法：c.prompt 与 sh.prompt 三处同口径一起清。
- 验证：生成后点清空，输入框为空。

### R17 shotAllFailed 被 draft 占位卡死 [已核实]
- 位置：`web/director/engine.js:12886`
- 问题：`every(c => ['failed','cancelled'].includes(c.status))` 对含 draft 占位（newShot 默认塞）的候选恒 false，批量失败镜永远进不了 todo，重试入口报「都已有生成结果」；同段注释声称修的就是这个场景。
- 改法：every 前 `filter(c => c.status !== 'draft')`。
- 验证：3 个失败镜（带 draft）断言「生成全部分镜」算进 todo。

### R18 问答面板 Ctrl+Enter 绕过 disabled [已核实]
- 位置：`web/ui/forms.js:358-363`
- 问题：`e.preventDefault(); goBtn.onclick();` 直调绕过 disabled，onSubmit 可跑两遍，两路流式并发写同一面板。

2. e2e 每文件自起 proxy + Chrome：35 次重复起停，单文件 35s 里大半是起停。
3. 无 watch：改一行也要手敲命令、手等 54s。
4. test:fast 只按文件映射（map.cjs 38 条规则 + 反查），不报耗时、不排序、不给预算。
